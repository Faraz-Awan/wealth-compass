# **App Name**: Wealth Compass

## Core Features:

- Contribution Input: Allow users to input annual retirement contributions.
- Return Rate Input: Enable users to specify an average annual investment return rate.
- Retirement Projection: Project the total retirement savings sum at the user's chosen retirement age.
- Percentage Breakdown Display: Visually display the percentage of the final retirement sum attributable to each year's contribution.
- Data Visualization: Presents data as interactive charts or graphs to show the growth trajectory and the impact of each year's investment.
- Scenario Analysis: Allows users to tweak the retirement age and the yearly income and then calculates the overall effect. An AI tool can assist to make personalized recommendation regarding yearly investments.

## Style Guidelines:

- Primary color: Forest green (#388E3C) to represent growth and stability.
- Background color: Pale green (#E8F5E9), a lightly desaturated hue related to forest green, for a calm, inviting background.
- Accent color: Sky blue (#5E35B1) to complement the green and provide a sense of clarity and trustworthiness. Use this on buttons to add contrast.
- Body and headline font: 'Inter', a sans-serif font to convey neutrality, and modernity.
- Use financial and growth-related icons to represent different aspects of retirement planning. Preferably outline style icons for clarity.
- Organize the calculator layout with clear sections for input, results, and visualization. Use a grid-based system to keep a professional appearance.
- Subtle transitions when calculating and displaying results. Hover animations for interactive elements. Use chart animations to draw attention.
